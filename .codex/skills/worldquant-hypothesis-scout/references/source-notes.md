Research implications:

- Alpha should forecast cross-sectional future returns and map to daily positions.
- Changes in data carry more useful information than static levels.
- Start from a market mechanism, then choose fields, transforms, horizons, and neutralization.
- Robust expression patterns include `rank`, `ts_rank`, `ts_zscore`, `ts_backfill`, `winsorize`, `group_neutralize`, `group_rank`, `hump`, and `trade_when`.
- Useful families include balance-sheet ratios, accounting quality, estimate revisions, news vector fields, volatility dislocations, and liquidity-conditioned reversals.
